# VetaStart — тестовая версия личного кабинета

**НЕ СЛИВАТЬ в main до проверки базы, безопасности и регистрации.** Все действующие сервисы Render используют main и авторазвёртывание.

## Уже в этой ветке
- Личный кабинет (тёмная и светлая темы), регистрация и вход, сохранение сценариев.
- PostgreSQL SQL-схема и миграция (`npm run migrate`).
- Черновики до 100 Instagram-аккаунтов на пользователя, но без реального OAuth; до 10 активных сценариев на аккаунт; до 5 сообщений.
- Предпросмотр тарифа 990 ₽/мес за первые три аккаунта + 299 ₽/мес за последующие.
- Получение и проверка Instagram webhook; фактической отправки сообщений нет.

## Локальная проверка
1. Установить Node.js 22+ и PostgreSQL.
2. `npm install`, настроить `DATABASE_URL` только в окружении.
3. `npm run migrate`, затем `npm test`, `npm run check` и `npm start`.
4. Проверить `/healthz`, регистрацию, вход/выход и разделение данных двух разных тестовых пользователей.

## Render staging
- Отдельный тестовый web service с веткой `staging/cabinet-v1`.
- Отдельная PostgreSQL в той же зоне. `DATABASE_URL` хранить только в secret environment variables.
- Для закрытого тестирования ограничить внешний доступ до доработки публичной регистрации.
- Бесплатная Render PostgreSQL временная, без резервных копий; не хранить там реальные клиентские данные.
- Текущие `META_APP_SECRET` и `INSTAGRAM_VERIFY_TOKEN` с продакшн-сервиса не переносить без необходимости.

## Что не готово
- Настоящий Meta OAuth, работа с Direct, проверка подписки, реальные клики/покупки.
- Робокасса, автоматические подписки, взыскание доплаты и управление реальным доступом.
- Email-верификация, восстановление пароля, полноценный аудит безопасности и защита от abuse.

До полноценного запуска пользователь должен понимать, что Instagram-аккаунты пока только черновики, а статус оплаты ещё не активен.
