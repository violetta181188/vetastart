# Проверка размещения VetaStart — 22 ноября 2026

Основной сервис https://vetastart-app-2026.onrender.com размещён на Render
из ветки codex/vetastart-saas-pilot-20261122. Авторазмещение отключено;
изменения main и других сайтов не публиковались. Код доступен в draft PR #2.

Сервис использует Node 24 и PostgreSQL из существующего staging-подключения.
Новые таблицы находятся в отдельной схеме vetastart_pilot. Исходные public
таблицы сохранены; совместимые пароли импортируются внутри базы, прежние
проекты доступны только для чтения. Новые платные ресурсы не создавались.
Бесплатная staging-база не заменяет постоянную коммерческую базу с резервированием.

Первое размещение полного PostgreSQL-приложения: commit 1d9179b,
deploy dep-dc1av1ff3r2c73c6nuu0, статус live. Проверены публичные ответы:
/health/live и /health/ready — 200, /app — 200, /api/customer/me без сессии — 401,
неподтверждённый webhook — 403. Readiness сообщает externalServicesVerified=false.

Проверки: 68 основных тестов и 16 интеграционных тестов на отдельной
локальной PostgreSQL 16. Тестовые операции не выполнялись на Render-базе.
Docker SQLite-вариант также проверен с непривилегированным пользователем,
постоянным томом и строгой проверкой TLS во время npm ci.

Регистрация, фоновая автоматизация, отправки и реальные платежи отключены.
Meta App ID, Unified Login configuration ID и redirect URI настроены.
Секреты сохраняются только через защищённые переменные; значения здесь отсутствуют.

Обновление проверки: владелец завершил Meta OAuth, на сервере подтверждено
активное зашифрованное подключение Unified Login. Handshake webhook успешен;
app-level подписка Meta активна и использует ожидаемый callback и поле messages.
Реальные входящие сообщения пока не зарегистрированы; отправки остаются выключенными.
Добавлена панель /operator для сценариев владельца на PostgreSQL и предпросмотра
без отправки. Проверки кода обновлены: 77 основных тестов и 17 PostgreSQL-тестов.

Для проверки реального сценария остаются:

- Почтовый отправитель: SMTP_HOST, SMTP_USER, SMTP_PASSWORD, MAIL_FROM;
  проверка доставки, затем включение почты и регистрации.
- Проверка одного настоящего входящего Direct и ответа перед включением автоматизации;
  вход владельца в Meta и настройка app-level webhook уже подтверждены.
- Подтверждение Робокассы, защищённые пароли и тестовая оплата;
  коммерческие платежи, фискализация, возвраты и регулярные списания пока не готовы.
- Постоянная база с резервным копированием перед коммерческим запуском.

Это размещённый пилот. Проверка внешних сервисов и готовность к продаже подписок
не подтверждены. Обновление SUAT через management API ещё не реализовано;
конфигурация business ID пока рассчитана на пилот владельца.
